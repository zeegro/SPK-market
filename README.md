# 🌭 Веб-сайт для автоматизации продаж ООО «СПК»

Курсовой проект (дипломная работа) — монолитное веб-приложение для автоматизации онлайн-продаж продукции мясоколбасного предприятия «Сибирская продовольственная компания».

Сайт решает задачу расширения каналов сбыта: клиенты могут ознакомиться с ассортиментом, собрать заказ в корзину и оформить доставку, а администраторы — управлять товарами, категориями и заказами через удобную панель.

## ✨ Возможности

**Для пользователей:**
- 📦 Каталог товаров с категориями и фильтрацией
- 🛒 Корзина с сохранением между сессиями (localStorage)
- 📝 Форма оформления заказа
- 📞 Форма обратной связи с прикреплением файлов
- 🗺️ Интеграция с Яндекс.Картами в разделе «Контакты»
- 📱 Адаптивный дизайн под мобильные устройства

**Для администратора:**
- 🔐 Защищённая авторизация
- 🛍️ Управление товарами (добавление, редактирование, удаление, скидки)
- 📂 Управление категориями
- 📋 Обработка заказов со сменой статусов
- 💬 Работа с сообщениями пользователей

## 🛠 Стек технологий

| Сторона | Технологии |
|---------|------------|
| Frontend | HTML5, CSS3, JavaScript |
| Backend | PHP 7.4+ |
| База данных | MySQL |
| Локальная среда | XAMPP (Apache + PHP + MySQL) |
| Архитектура | Монолитное веб-приложение |

## 📁 Структура проекта
```
spk-market/
├── assets/              # CSS, JS, изображения
├── includes/            # Подключаемые модули (header.php, footer.php, db.php)
├── templates/           # Шаблоны страниц
├── uploads/             # Загружаемые пользователями и админом файлы
├── documentation/       # Техническая документация
├── admin/               # Административная панель
├── index.php            # Главная страница
├── catalog.php          # Каталог товаров
└── contacts.php         # Контакты
```
