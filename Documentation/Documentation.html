Структура папок

Вот как организованы файлы проекта:

  • assets/ - содержит все медиафайлы:
    • css/ - CSS-файлы для стилей.
    • images/ - изображения для сайта, включая логотипы и товарные изображения.
    • js/ - JavaScript-файлы для интерактивности.
  • css/ - основные CSS-файлы для дизайна.
  • includes/ - вспомогательные PHP-файлы для подключения частей страниц (например, футера и хедера).
  • templates/ - шаблоны для различных страниц сайта.
  • uploads/ - директория для загрузки пользовательских файлов (например, изображений товаров или сообщений).
  • Documentation/ - папка для данной документации.
  • .php-файлы - основные страницы сайта (index.php, catalog.php, contacts.php и т.д.).

HTML-структура

На сайте используются следующие основные разделы:

  • Хедер (header.php) - содержит логотип, меню навигации и другие элементы верхней части страницы.
  • Футер (footer.php) - содержит контактную информацию, ссылки на социальные сети и другие элементы нижней части страницы.
  • Главная страница (index.php) - отображает слайдер, категории товаров и популярные продукты.
  • Каталог товаров (catalog.php) - список всех доступных товаров с возможностью фильтрации по категориям.
  • Контакты (contacts.php) - форма обратной связи и контактная информация.
  • О компании (about.php) - информация о вашей компании.
  • Корзина (cart.php) - управление корзиной пользователя.
  • Админ-панель (admin.php) - панель администрирования для управления товарами, заказами и сообщениями.

Шаблоны страниц (templates/) используются для повторного использования общих элементов (например, header и footer).

CSS-структура

Основной CSS-файл: css/style.css.

Используются внешние шрифты из Google Fonts:

  • @font-face { font-family: 'Montserrat'; ... }
  • @font-face { font-family: 'Manrope'; ... }
  • @font-face { font-family: 'Mark Script'; ... }

Шрифты подключаются через https://fonts.googleapis.com/css2?family=Montserrat :wght@400;700&family=Manrope:wght@400;700&family=Mark+Script&display=swap.

JavaScript

На сайте используются следующие JavaScript-файлы:

  • js/script.js - общий скрипт для слайдера, модальных окон и других интерактивных элементов.
  • js/form-validation.js - валидация форм обратной связи и оформления заказа.

Пример реализации слайдера:

                const slider = document.querySelector('.slider');
                const slides = document.querySelectorAll('.slide');
                const dots = document.querySelectorAll('.dot');
                if (slider && slides.length > 0 && dots.length > 0) {

                    function updateSlider() {
                        slider.style.transform = `translateX(-${currentIndex * 100}%)`;
                        dots.forEach(dot => dot.classList.remove('active'));
                        if (dots[currentIndex]) {
                            dots[currentIndex].classList.add('active');
                        }
                    }
                    // Остальной код...
                }

Форма обратной связи

На сайте есть форма обратной связи в разделе "Контакты".

Форма обратной связи позволяет пользователям отправлять сообщения с указанием имени, телефона, электронной почты и текста сообщения. Файлы также могут быть прикреплены к сообщению.

Сообщения сохраняются в таблице messages в базе данных.

Админ-панель

В шаблоне предусмотрена админ-панель для управления контентом сайта. Ниже приведена информация о её функционале.

1. Вход в админ-панель

Для входа в админ-панель перейдите по адресу: ../admin.

Логин и пароль по умолчанию:

  • Логин: admin
  • Пароль: 12345

Чтобы сменить логин и пароль, отредактируйте файл login.php. Измените следующие строки:

        if ($login === 'admin' && $password === '12345') {
            // Логика авторизации
        }

Замените значения 'admin' и '12345' на новые данные.

2. Выход из админ-панели

Чтобы выйти из админ-панели, нажмите кнопку "Выйти из аккаунта" на странице ../admin.

3. Разделы админ-панели

Админ-панель содержит следующие разделы:

  • Управление товарами
  • Управление категориями
  • Заказы
  • Сообщения с формы
3.1. Управление товарами

В этом разделе можно добавлять, редактировать и удалять товары:

  • Чтобы добавить товар, заполните все поля в форме и нажмите кнопку "Добавить товар". Товар появится в списке товаров ниже формы добавления.
  • Чтобы изменить товар, найдите его в списке и нажмите кнопку "Изменить товар". Форма редактирования появится внизу страницы. Внесите изменения в нужные поля и нажмите "Сохранить изменения".
  • Чтобы удалить товар, нажмите кнопку "Удалить" рядом с ним.
3.2. Управление категориями

В этом разделе можно добавлять, редактировать и удалять категории:

  • Чтобы добавить категорию, введите её название в поле и нажмите "Добавить".
  • Ниже находится список всех категорий. Чтобы отредактировать категорию, нажмите "Редактировать". Форма редактирования появится внизу страницы. Измените название и нажмите "Сохранить изменения".
  • Чтобы удалить категорию, нажмите "Удалить" рядом с ней.
3.3. Заказы

В этом разделе отображаются заказы, оформленные покупателями:

  • Заказы можно фильтровать по статусу доставки. Для этого справа от каждого заказа нажмите кнопку, соответствующую текущему статусу (например, "В обработке", "Доставлен").
  • Если статус заказа "Отменён", это означает, что пользователь отменил заказ после оформления.
3.4. Сообщения с формы

В этом разделе находятся сообщения, отправленные пользователями через форму в разделе Контакты:

  • Каждому сообщению можно установить статус "Прочитано", нажав соответствующую кнопку.
  • Чтобы удалить сообщение, нажмите кнопку "Удалить".

База данных

Для работы сайта необходима база данных с четырьмя таблицами:

  • categories - содержит категории товаров.
  • messages - содержит сообщения из формы обратной связи.
  • orders - содержит информацию о заказах.
  • products - содержит информацию о товарах.

Пример структуры таблиц:

                -- Таблица categories
                CREATE TABLE categories (
                    id INT PRIMARY KEY AUTO_INCREMENT,
                    name VARCHAR(100) NOT NULL UNIQUE,
                    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
                );
        
                -- Таблица messages
                CREATE TABLE messages (
                    id INT PRIMARY KEY AUTO_INCREMENT,
                    name VARCHAR(100),
                    phone VARCHAR(20),
                    email VARCHAR(100),
                    message TEXT,
                    file_path VARCHAR(255),
                    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
                    is_read TINYINT DEFAULT 0
                );
        
                -- Таблица orders
                CREATE TABLE orders (
                    id INT PRIMARY KEY AUTO_INCREMENT,
                    customer_name VARCHAR(100),
                    phone VARCHAR(20),
                    email VARCHAR(100),
                    address TEXT,
                    product_ids JSON NOT NULL,
                    total_price DECIMAL(10, 2) NOT NULL,
                    status ENUM('новый', 'в обработке', 'выполнен', 'отменён') DEFAULT 'новый',
                    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
                );
        
                -- Таблица products
                CREATE TABLE products (
                    id INT PRIMARY KEY AUTO_INCREMENT,
                    category_id INT,
                    name VARCHAR(255) NOT NULL,
                    description TEXT,
                    price DECIMAL(10, 2) NOT NULL,
                    discount DECIMAL(10, 2),
                    image VARCHAR(255),
                    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
                    additional_info TEXT,
                    additional_info2 TEXT
                );
